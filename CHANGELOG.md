# Changelog

Все заметные изменения HydroLauncher. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют
[семантическому версионированию](https://semver.org/lang/ru/).

## [0.2.0] — в разработке

### Исправлено
- Скачивание файлов стало устойчивым к обрывам: общий HTTP-клиент с
  таймаутами, до трёх повторов при сетевых ошибках, `429` и `5xx`,
  соблюдение заголовка `Retry-After`, докачка во временный файл и проверка
  SHA-1 перед перемещением на место.
- Загрузка сборок `.mrpack` идёт параллельно (с ограничением числа
  одновременных загрузок), а при ошибке частично установленная сборка
  удаляется, а не остаётся «полупустой» в списке.
- Падение игры больше не считается нормальным выходом: состоянием `exited`
  считается только код возврата `0` или ручная остановка, всё остальное
  показывается как `crashed` с кодом в событии.
- Настройка «Сворачивать лаунчер при запуске игры» теперь действительно
  сворачивает окно в панель задач и возвращает его после выхода из Minecraft.
- Смена папки данных сразу перечитывает сборки и профили — без перезапуска
  лаунчера в интерфейсе не остаётся данных из старой папки.
- Хеши скачанных файлов считаются потоково, а не загрузкой файла целиком в
  память: большие архивы больше не съедают сотни мегабайт ОЗУ.
- Запросы к GitHub API кэшируются на 10 минут, поэтому список сборок Horizon и
  проверка обновлений не упираются в лимит 60 запросов в час; при исчерпании
  лимита показывается понятное сообщение вместо «HTTP 403».

### Безопасность
- Включена Content Security Policy: интерфейсу разрешены только свои скрипты,
  стили и шрифты, изображения с `https:`/`data:`/`blob:` и IPC-канал Tauri.
- Внешние ссылки открываются только по `https`, длина ограничена.
- Адреса веб-страниц проектов и префикс манифеста Mojang вынесены в
  `config/endpoints.rs` вместо хардкода в коде интерфейса.

### Изменено
- Версия в `User-Agent` берётся из `Cargo.toml`, а не задаётся вручную.
- Неиспользуемые команды `get_version_details` и `instance_store` убраны из
  списка обработчиков Tauri.
- Мок-API для браузерной разработки дополнен всеми командами интерфейса.

### Добавлено
- Модульные тесты фронтенда (Vitest) на логику дока сборок, видимость
  обновлений и контракт «каждая команда `api` есть в моке».
- Тесты бэкенда на повторы загрузки, классификацию завершения процесса и
  потоковый SHA-1.
- CI на GitHub Actions: типы, сборка и тесты фронтенда, `cargo check` и
  `cargo test` бэкенда.

## [0.1.1] — 2026-11-15

### Добавлено
- Проверка обновлений самого лаунчера: тихая строка «доступно X.Y.Z» слева от
  профиля и блок «О программе» в настройках со ссылкой на страницу релиза.
  Автоматической загрузки нет; уведомление можно скрыть.
- Показ установленной версии движка Horizon в параметрах сборки
  («Установлено: nightly · дата»).
- Сборка релизов через GitHub Actions: тег `v*` автоматически создаёт релиз
  с портативным `.exe`, установщиками NSIS и MSI.
- `CHANGELOG.md` и раздел «Релизы» в README.

### Исправлено
- Разные сборки Horizon больше не перетирают бинарники друг друга: движок
  хранится отдельно для каждого тега (`runtimes/horizon/bin/<tag>`), а
  подготовленные ресурсы — в `prepared/<версия>/<tag>`. Старая однослотовая
  раскладка автоматически переносится при первом запуске.
- Док сборок внизу главной страницы сортируется по последней активности
  (`lastPlayedAt`, затем `createdAt`), показывает не больше шести последних
  сборок и компактный `+N` со ссылкой на страницу «Сборки». Выбранная сборка
  всегда остаётся в доке, горизонтальная прокрутка убрана.

## [0.1.0] — 2026-11-14

Первый публичный релиз.

### Добавлено
- Изолированные сборки Minecraft Java Edition: Vanilla, Fabric, Forge,
  NeoForge, Quilt и импорт `.mrpack`.
- Нативный движок Horizon (Rust): запуск без JVM, выбор версии бинарников и
  автообновление nightly-сборок.
- Каталог модов Modrinth и Horizon с фильтрами по загрузчику и версии игры,
  SWR-кэшем и фоновой предзагрузкой при старте.
- Офлайн-профили (`OfflinePlayer:<name>`, UUID v3) с быстрым переключением и
  удалением с подтверждением.
- Автоматический подбор и загрузка Java (Eclipse Temurin), в том числе
  быстрая установка Java 25.
- Быстрый запуск сохранённых миров и серверов с главной страницы.
- Изолированная консоль для каждой сборки с копированием и очисткой логов.
- Три темы оформления — «Сумерки», «Ночь», «День» — в стиле «жидкого стекла».
